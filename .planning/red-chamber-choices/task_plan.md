# 任务计划：红楼拾章（暂名）

## 目标

在 pnpm monorepo 中新建独立小工具 `apps/red-chamber-choices/`。玩家选择一位《红楼梦》女性角色，沿她的故事地图逐站点亮，选择如何回应场景中的处境。前一站的选择改变下一站的对话，完成全线后获得三项评分、结局分类和对应徽章。

## 下一步

如继续制作首发内容，沿用单线原型的数据结构，补齐薛宝钗和王熙凤路线。

## 关键问题

1. 地图首先服务于阅读顺序。选角后显示对应地点与跨回目路线，共用园景底图；早于大观园的场景在园外单独标注。
2. 分支是否值得重玩。每个选项先给出当场反馈，再在下一站交代具体后果；跨站回扣和结局引用历史选择。
3. 每条路线在选定场景收束，以游戏尾声反馈选择。制作时统一标注原著回目、改编对话和游戏尾声。

## 已做决策

以下为提案默认值，可随首条路线试听调整。

| 决策 | 理由 |
| --- | --- |
| 先做黛玉单线原型，首发再加入宝钗和凤姐 | 先验证地图到徽章的完整体验，再用人情、礼数和治事差异丰富重玩 |
| 固定场景顺序，变化落在对话、态度和尾声 | 保持原著事件的次序，让每个选项产生可读的后果，控制台词组合规模 |
| 采用护己、顾情、谋事三项评分 | 反馈玩家在故事中的取舍，同一套规则跨角色复用 |
| 单角色四站，每站三个选项 | 能用有限的内容测试跨站分支、评价及重玩 |
| 项目使用手机竖屏，采用原创新绘和改编台词 | 便于单手阅读和操作，统一场景、人物和徽章的画风 |
